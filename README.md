如何使用自己的域名？

Settings -> Secrets and variables -> Actions -> Repository secrets 添加以下两个 Key：

CF_ZONE_ID：点击你的域名 在 Cloudflare 托管面板右侧获得的 Zone ID。

CF_API_TOKEN：具备 Zone.DNS - Edit 权限的 Cloudflare API Token。
